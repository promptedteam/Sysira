# Sysira

Sysira is a Windows desktop app for reviewing file changes, moves, network connections, Windows activity, and security alerts in one place.

Setup is recommended for a normal Windows installation. Portable runs without installing. MSI is provided for managed or scripted deployment. All three downloads contain the same Sysira application.

## Downloads and updates

The download icon beside Sysira's light/dark mode control checks this repository's latest release in the background. It shows Setup, Portable, MSI, and release-note links. Sysira does not silently install updates.

This repository publishes downloads and product screenshots only; the Rust application source code is not published here. GitHub may offer automatic “Source code” archives of this documentation repository, which do **not** contain the application source.
